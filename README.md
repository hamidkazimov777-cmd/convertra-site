## Overview

This repository contains the source code for the landing page and distribution site of **[Convertra](https://github.com/hamidkazimov777-cmd/convertra)**. 

It is built with Astro for maximum performance and zero-JS static generation, deployed on Cloudflare Pages. 

### Why this exists?
While Convertra is a native macOS application, this site serves as its digital storefront. It highlights the design aesthetics, the power of the **Convertra AudioCore** DSP engine, and provides download links for the macOS binaries.
