# Convertra macOS — Guía de instalación

## Requisitos del sistema
- macOS 13.0 (Ventura) o posterior.
- Procesador Apple Silicon (M1/M2/M3) o Intel.
- ~15 MB de espacio libre en el disco.

## Pasos de instalación
1. Descarga el archivo `Convertra.zip` desde nuestro sitio web.
2. Localiza el archivo descargado en tu carpeta de **Descargas** (Downloads).
3. Haz doble clic en `Convertra.zip` para extraerlo.
4. Arrastra y suelta la aplicación extraída **Convertra.app** en tu carpeta de **Aplicaciones** (Applications).
5. Inicia Convertra desde tu carpeta de Aplicaciones o Launchpad.

## Solución de problemas
**"Convertra.app no se puede abrir porque el desarrollador no puede ser verificado"**
- Abre **Configuración del sistema** > **Privacidad y seguridad**.
- Desplázate hacia abajo hasta la sección **Seguridad**.
- Haz clic en **Abrir de todos modos** (Open Anyway) junto a la advertencia sobre Convertra.
- Haz clic en **Abrir** en el mensaje que aparece.
