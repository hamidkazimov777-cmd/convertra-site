# Convertra macOS — Инструкция по установке

## Системные требования
- macOS 13.0 (Ventura) или новее.
- Процессор Apple Silicon (M1/M2/M3) или Intel.
- ~15 МБ свободного места на диске.

## Установка
1. Скачайте архив `Convertra.zip` с нашего сайта.
2. Найдите скачанный файл в папке **Загрузки** (Downloads).
3. Дважды кликните по `Convertra.zip`, чтобы распаковать его.
4. Перетащите распакованное приложение **Convertra.app** в папку **Программы** (Applications).
5. Запустите Convertra из папки Программы или Launchpad.

## Решение проблем
**"Приложение Convertra.app не может быть открыто, так как разработчик не может быть проверен"**
- Откройте **Системные настройки** > **Конфиденциальность и безопасность**.
- Прокрутите вниз до раздела **Безопасность**.
- Нажмите **Все равно открыть** (Open Anyway) рядом с предупреждением о Convertra.
- Нажмите **Открыть** в появившемся окне.
